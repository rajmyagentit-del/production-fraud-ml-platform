Model & Data Drift Monitoring

Chronological monitoring compares the model reference period with later PaySim transactions. PSI is used for numerical features and model-score distributions, while total variation is used for transaction type. Held-out model performance is reported separately so distribution drift is not confused with model failure.

Model Lifecycle & Retraining

Drift-triggered retraining trains a challenger model separately from the production model. Champion and challenger are evaluated on the same untouched future window before the challenger can be approved for review. Production replacement is never automatic.
